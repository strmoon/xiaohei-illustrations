# 生图提示词模板

每张图单独生成。根据正文内容替换变量，不要把多张图拼在一起。

```text
生成一张独立的 16:9 横版中文文章配图。

视觉 DNA：
纯白背景。极简黑色手绘线稿。略微摇摆、不均匀的笔触。保留大量白色留白。少量红色、橙色、蓝色的中文手写批注。呈现干净、荒诞的产品草图感。不要渐变、阴影、纸张纹理、复杂背景、商业矢量风格、PPT 信息图质感、可爱吉祥物海报、儿童插画或写实 UI。

必须使用的固定 IP 角色：
小黑：一个小型纯黑色荒诞生物，白色圆点眼睛、细小的腿、空白而严肃的表情、略微不规则的手绘身体轮廓。小黑必须完成画面核心的概念动作，而不是作为装饰。让小黑显得严肃、冷面、略带怪诞，而不是可爱。

主题：
{正文配图主题}

结构类型：
{结构类型：Workflow / 系统局部 / 前后对比 / 角色状态 / 概念隐喻 / 方法分层 / 地图路线 / 小漫画分镜}

核心意思：
{这张图要表达的核心意思}

构图：
{具体画面：小黑在哪里、正在做什么、主要物件是什么、信息如何流动}

建议元素：
{元素1} / {元素2} / {元素3} / {元素4}

中文手写标注：
{标注词1} / {标注词2} / {标注词3} / {标注词4} / {可选标注词5}

颜色使用：
黑色用于主要线稿和小黑。橙色用于主要流程、路径或箭头。红色仅用于关键警告、问题或结果。蓝色仅用于次要注释、反馈或系统状态。

约束：
一张图只解释一个核心结构。主体约占画布的 40%-60%。至少保留 35% 的白色留白。最多使用 5-8 个简短的中文手写标注。不要在左上角写标题。不要把结构类型写在图中。不要做成正式图表、课程幻灯片或信息密度过高的说明图。除非明确要求，否则不要复制既有示例或复用已知案例的构图；请为这篇文章创造一个新鲜的视觉隐喻。画面应清晰但不具有说明书感，有趣但不幼稚，怪诞但干净。
```
